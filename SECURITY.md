# Security

Please do not publish secrets, personal examples, screenshots of confidential fields or private vault files in issues.

The local model endpoint is authenticated and loopback-only. App text is never used to construct shell commands or remote source URLs. Source checks accept selected HTTPS domains, do not send cookies, reject cross-host redirects and impose a size limit. Native insertion validates the exact application, field, text and collapsed selection immediately before posting Unicode events. Unsupported fields fail closed.

Local inference still processes text in memory. AES-GCM and Keychain do not protect against an attacker already controlling the same logged-in session. Application exclusions are the strongest practical control for confidential apps. Treat generated prose as unverified. A reference containing an answer does not prove the answer is correct in context.

Before a release, run tests, inspect the public export, check dependency versions, and validate the actual signed application on a Mac. No general guarantee of compatibility or factual accuracy is made.
